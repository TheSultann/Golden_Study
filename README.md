# Golden Study CRM

CRM одного учебного центра для управления студентами, группами, посещаемостью, финансами и связью с родителями через Telegram.

## Статус

Создан pnpm monorepo и базовый React + Vite frontend.

## Запуск

```bash
corepack pnpm install
corepack pnpm dev
```

## Проверки

```bash
corepack pnpm test
corepack pnpm lint
corepack pnpm typecheck
corepack pnpm build
```

- React + Vite + TypeScript.
