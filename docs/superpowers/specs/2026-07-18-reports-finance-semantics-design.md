# Hisobotlar: понятные финансовые показатели

## Цель

Сделать финансовые показатели в `Hisobotlar` понятными с первого взгляда без тяжёлых цветных блоков.

## Дизайн

- Вкладка `Kirim-chiqim` показывает четыре карточки в едином стиле:
  - `Kirim` — зелёный смысловой акцент и иконка входящего потока.
  - `Chiqim` — красный смысловой акцент и иконка исходящего потока.
  - `Sof foyda` — главная карточка. Зелёная при положительном результате, красная и с названием `Zarar` при отрицательном.
  - `Operatsiyalar` — нейтральная карточка.
- Вкладка `Tushumlar` использует зелёный акцент для общей суммы.
- Вкладка `Qarzlar` использует красный акцент для общей задолженности.
- Цвет используется только как дополнительный сигнал: каждая карточка сохраняет текстовую подпись и иконку.
- Стиль остаётся компактным: мягкий фон, тонкая граница, сумма 16 px, без градиентов и тяжёлых заливок.

## Адаптивность

- Desktop: четыре карточки в одну строку.
- Mobile: сетка 2×2.
- Суммы переносятся безопасно и не создают горизонтальный скролл.

## Данные и архитектура

- Новые API или бизнес-данные не нужны.
- Используются существующие `finance.transactions` и `finance.summary.profit`.
- Если прибыль отрицательная, интерфейс показывает абсолютную сумму под названием `Zarar`.

## Проверка

- Тест проверяет семантические классы дохода, расхода, прибыли и нейтрального показателя.
- Отдельный тест проверяет название `Zarar` для отрицательного результата.
- После реализации запускаются `test`, `lint`, `typecheck`, `build`.
