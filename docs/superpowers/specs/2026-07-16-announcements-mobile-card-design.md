# E’lonlar: mobile-карточка объявления

## Цель

Убрать перенос статуса доставки в отдельную строку и сохранить компактную, понятную иерархию карточки.

## Решение

- Mobile header остаётся трёхколоночным: иконка, контент, статус.
- Статус закрепляется справа сверху и не переносится внутри badge.
- Название и metadata безопасно сжимаются и переносятся без наложения на статус.
- Дата показывается строго в `DD.MM.YYYY`.
- Mobile padding/gap уплотняются без уменьшения читаемости.
- Карточка не получает ложный pointer/hover, потому что действия по клику нет.
- Поддерживаются `Yetkazildi`, `Rejalangan`, `Navbatda`, `Xato`, `Qoralama`.

## Проверка

- Regression-тест проверяет семантические классы header/content/status и формат даты.
- CSS-контракт проверяет три mobile-колонки и `white-space: nowrap` badge.
- Запустить `test`, `lint`, `typecheck`, `build`.
- Browser/Playwright не запускать по просьбе пользователя.
