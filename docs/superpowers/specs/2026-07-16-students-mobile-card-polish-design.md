# Students Mobile Card Polish Design

## Цель

Точечно исправить мобильный вид раздела `O‘quvchilar`: выровнять кнопку действий, типографику карточки и кнопки заголовка без изменения бизнес-логики и других экранов.

## Причина дефекта

В `apps/web/src/index.css` одновременно действуют несколько дублирующих `@media (max-width: 760px)` для `.students-table`. Старый блок ожидает имя в `span`, хотя актуальная разметка выводит имя в `strong`. Более поздние переопределения также конфликтуют по `display`, сетке, отступам и позиционированию последней ячейки.

## Решение

- Оставить один финальный mobile-блок для списка учеников.
- Карточка: имя — основной текст, ID — вторичный текст под именем.
- Остальные строки: единая сетка `72px minmax(0, 1fr)`.
- Кнопка `…`: в правом верхнем углу, визуально и математически центрирована в зоне `40×40px`.
- Кнопки экспорта и добавления: `40×40px`, иконки `16px`, без текста на mobile.
- Desktop-разметку, dropdown portal, данные и действия не менять.

## Проверка

- Regression test проверяет доступные имена кнопок и структуру карточки.
- Mobile QA на ширине около `390px`: нет наложений, текст выровнен, dropdown открывается.
- Desktop smoke QA: таблица и кнопки сохраняют текущий вид.
- Запустить test, lint, typecheck, build.
