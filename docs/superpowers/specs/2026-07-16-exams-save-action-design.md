# Imtihonlar: размещение сохранения результатов

## Цель

Сделать завершение редактирования результатов очевидным: пользователь вводит баллы и комментарии сверху вниз, затем сохраняет изменения в конце списка.

## Решение

- Удалить кнопку `Natijalarni saqlash` из заголовка таблицы.
- Заголовок оставить информационным: экзамен, группа, дата, максимальный балл.
- После списка результатов добавить контекстную панель действий.
- Показывать панель только при несохранённых изменениях, сохранении, успехе или ошибке.
- Desktop: статус слева, кнопка справа.
- Mobile: статус над кнопкой, кнопка занимает всю ширину.
- Не менять repository, API-контракты и бизнес-логику сохранения.

## Состояния

- Dirty: `Saqlanmagan o‘zgarishlar`, кнопка активна.
- Pending: кнопка заблокирована, текст сообщает о сохранении.
- Success: краткое подтверждение успешного сохранения.
- Error: понятное сообщение, повторное сохранение доступно.
- Clean: панель скрыта.

## Проверка

- Regression-тест: кнопка отсутствует в header и появляется после изменения результата.
- Regression-тест: action-панель расположена после таблицы.
- Responsive CSS-контракт: desktop alignment и mobile full-width.
- Запустить `test`, `lint`, `typecheck`, `build`.
- Browser/Playwright QA не выполнять по просьбе пользователя.
