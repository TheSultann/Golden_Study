# Карточка ученика — дизайн

## Цель

Дать администратору быстрый обзор личных, учебных и финансовых показателей ученика без перегрузки общего реестра и без потери текущих фильтров списка.

## UX

- Клик по основной части строки ученика открывает drawer справа.
- Кнопка `…` продолжает открывать меню действий и не открывает drawer.
- Desktop: drawer шириной 380–420 px поверх списка.
- Mobile: полноэкранная панель.
- Закрытие: кнопка `Yopish`, клик по backdrop и `Escape`.
- Состояние поиска, вкладки и прокрутки реестра сохраняется.

## Содержимое

1. Шапка: Ф.И.О., ST-ID, статус, группы.
2. Учебная сводка:
   - общий балл рейтинга;
   - место в группе;
   - средний результат экзаменов;
   - посещаемость в процентах;
   - выполнение домашних заданий в процентах.
3. Финансы: текущий баланс.
4. Контакты: телефон ученика, родитель, телефон родителя, адрес.
5. Действия: `Tahrirlash` и `Yopish`.

Историю по месяцам, графики, платежи и журнал посещаемости в первую версию не добавлять.

## Данные и архитектура

Единый поток:

`StudentProfileDrawer → useStudentProfile(studentId) → StudentProfileRepository → MockStudentProfileRepository / ApiStudentProfileRepository`

Контракт `StudentProfile` хранится в `packages/contracts` и содержит:

- базовый объект ученика;
- `academicSummary`: `ratingScore`, `groupPlace`, `examAveragePercent`, `attendancePercent`, `homeworkPercent`;
- `updatedAt`.

UI не импортирует mocks и не пересчитывает агрегаты. Mock repository возвращает готовую сводку асинхронно. Будущий API должен рассчитывать агрегаты по всей актуальной истории ученика, а не по одной дате посещаемости.

## Состояния

- Loading: skeleton внутри drawer.
- Error: короткое сообщение и кнопка `Qayta urinish`.
- Empty academic data: `Ma’lumot yetarli emas`, без фиктивных нулей.
- После редактирования ученика invalidation списка и профиля.

## Адаптивность и доступность

- Drawer имеет `role="dialog"`, `aria-modal="true"` и связанный заголовок.
- Фокус переводится в drawer и возвращается на строку после закрытия.
- Все показатели имеют текстовые подписи; цвет не является единственным индикатором.
- На mobile показатели строятся сеткой 2×2, длинные контакты переносятся.

## Тесты

- Unit: корректное отображение заполненной и пустой учебной сводки.
- Integration: открытие строкой, закрытие, сохранение фильтров, retry после ошибки.
- Regression: меню `…` не открывает drawer.
- Responsive CSS: desktop drawer и mobile full-screen layout.

## Вне scope

- Отдельный маршрут `/students/:id`.
- Графики и история по периодам.
- Изменение формулы рейтинга.
- Backend endpoint и серверные агрегаты.
